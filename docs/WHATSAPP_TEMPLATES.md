# WhatsApp templates to submit for approval

The first batch for the platform's WhatsApp number (ADR-048 item 12, ADR-060 item 5): every message a shop can get, and the salesman's handover reminder. Each language is a separate translation of the same template name; until a language's translation is approved, messages in it go in English. The texts are machine drafts until a native speaker reviews them (pre-production item 42); approval is recorded per language on the super admin's Default texts page.

Generated by `manage.py whatsapp_submissions` (re-run after changing a text). TODO(verify): the provider's language codes for Hindi and Marathi, its category rules, and its sample requirements.
